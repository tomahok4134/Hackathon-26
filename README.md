## ハッカソンで語れなかったひとりごと
3私のメンバーのうち私まめーんだけで70%以上開発したこのシステム。未完成な要素に脆弱な仕様が多々ありますが、そんな中細かなところでのUX改善をがんばりました。  
結局内部までは見られないイベントなので、中身を作り込む必要ないんですよ。  
でも簡易ながらセッション管理にパスワード管理、更新や削除リクエストに対するユーザ認証の要求などアカウント関係は結構しっかり作ってるんですよ。  
これしかもバックエンド含め85%くらいは本番2日前から作り始めたんですわ。  
自分でもびっくりしたよ、バックエンドもフロントエンドもどっちも担当して2日で発表できる程度まで仕上げられたの。  
ハッカソン(期間2ヶ月)だからハッカソンかどうか怪しいけど。  
まぁ例のツールから逃げてHTML CSS JS TSを触るのは楽しかったですね...
